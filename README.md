# Fly Chicken WhatsApp Gateway (Electron EXE)

تطبيق لسطح المكتب (Windows) يحول جهاز الكاشير إلى بوابة إرسال OTP عبر واتساب بشكل تلقائي ومجاني دون الحاجة لـ CMD أو اشتراكات شهرية.

## المميزات:
1. واجهة رسومية بسيطة تمسح منها QR Code لمرة واحدة.
2. يعمل تلقائياً في الخلفية في شريط المهام (System Tray) بجانب الساعة.
3. يعمل تلقائياً مع تشغيل جهاز الويندوز (Auto-launch on startup).
4. يوفر API محلي لاستقبال طلبات التحقق من تطبيق الزبون عبر المنفذ `3000`.

## طريقة البناء تلقائياً عبر GitHub:
1. أنشئ مستودعاً جديداً (New Repository) على GitHub.
2. ارفع هذه الملفات إلى المستودع.
3. سيقوم GitHub Actions ببناء ملف الـ `EXE` تلقائياً عبر مسار الـ Workflows.
4. اذهب إلى تبويب **Actions** وحمّل ملف التثبيت المباشر `FlyChicken-WAGateway Setup.exe`.
